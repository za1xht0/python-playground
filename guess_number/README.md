# Guess the Number

Консольная игра: программа загадывает число, пользователь пытается угадать.

## Как запустить

```bash
python guess_number.py
```

## Пример работы

```
Угадай число от 1 до 100: 50
Больше!
Угадай число от 1 до 100: 75
Меньше!
Угадай число от 1 до 100: 63
Поздравляю, вы угадали!
```

## Что использовано

- модуль `random`
- цикл `while`
- обработка пользовательского ввода
