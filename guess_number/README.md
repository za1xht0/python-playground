# Guess the Number

Консольная игра: программа загадывает число, пользователь пытается угадать.

## Как запустить

```bash
python guess.py
```

Из корневой папки репозитория:

```bash
python guess_number/guess.py
```

## Пример работы

```
Напиши предположение:50
Загаданное число больше
Напиши предположение:75
Загаданное число меньше
Напиши предположение:63
Ты угадал число!
```

## Ограничения

- За одну игру даётся 10 попыток.
- Загадывается целое число от 1 до 100.
- Ввод должен быть целым числом, иначе программа завершится с ошибкой.
