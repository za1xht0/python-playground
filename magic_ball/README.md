# Magic Ball

Магический шар, отвечающий на любой вопрос.

## Как запустить

```bash
cd magic_ball
python magic.py
```

## Пример работы

```
Я - магический шар. Отвечу на любой твой вопрос!
Напиши свой вопрос:
Эта программа работает?
Скорее всего да.
Если хочешь закончить, напиши -  закончить. Иначе напиши - продолжаем.
закончить
```

## Ограничения

- Ответы выбираются случайно из заранее заданного списка.
- Программа не проверяет содержание вопроса.
- Для завершения нужно ввести `закончить` после ответа.
