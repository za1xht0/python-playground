# Конвертер единиц измерения.

Программа переводит одни единицы измерения в другие. Конвертирует километры в мили, температуру из Цельсия в Фаренгейт, килограммы в фунты, сантиметры в дюймы и литры в галлоны.

## Как запустить

```bash
cd unit_converter
python unit_con.py
```
