# Бросок кубика против ПК.

Игра, в которой игрок и компьютер по очереди бросают кубики. Побеждает тот, кто первым наберет 3 победы.

## Как запустить

```bash
cd dice_roll
python dice_roll.py
```

## Пример работы

```
Игра бросок кубика.
Побеждает тот, кто первым наберет 3 победы.
ты победил в этом раунде. у тебя выпало 5, у пк было 2
Счетчик твоих побед: 1
Счетчик побед пк: 0
ты проиграл в этом раунде. у тебя выпало 1, у пк было 4
Счетчик твоих побед: 1
Счетчик побед пк: 1
ничья
ты победил в этом раунде. у тебя выпало 6, у пк было 3
Счетчик твоих побед: 2
Счетчик побед пк: 1
ты победил
```
