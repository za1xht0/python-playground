# Простой калькулятор

Программа принимает два числа от пользователя, какой тип вычислений провести и считает.

## Пример работы

```
калькулятор
Введите первое число:12
Введите второе число:12
Выберите фукнцию:
1. Сложить
2. Вычесть
3. Умножить
4. Разделить
Введите номер выбранной операции
1
12 + 12 = 24
Продолжаем? Напиши да или нет
нет
```
