# Генератор никнеймов

Программа генерирует случайный никнейм из прилагательного и существительного на английском языке.

## Пример работы

```
Генератор ников
Программа берет случайное существительное и прилагательное и делает из них ник
Ваш ник - Venom_Nomad
```
