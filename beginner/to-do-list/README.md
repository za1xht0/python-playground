# To-Do List

Консольное приложение для управления задачами: просмотр списка, добавление новых задач и удаление уже выполненных.

## Пример работы

```
==================
    To-Do List
==================

1. Show tasks

2. Add task

3. Remove task

4. Exit

Choose an option:
2
Enter task:
Купить хлеб
Task added

==================
    To-Do List
==================

1. Show tasks

2. Add task

3. Remove task

4. Exit

Choose an option:
1
Tasks:
1. Купить хлеб
```
