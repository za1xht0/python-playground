# Генератор случайных паролей 

Программа генерирует случайные пароли, состоящие из букв разных регистров, цифр и знаков.

## Как запустить

```bash
cd password_generator
python pass.py
```

## Пример работы

```
Это генератор паролей.
Он генерирует случайный пароль из 12 знаков, включая цифры, буквы, символы.
Вот ваш пароль: (4M+95!)y3Ej
Если хочешь закончить, напиши - закончить
Если продолжаем - напиши продолжаем
продолжаем
Вот ваш пароль: +a!29w)v7Y6$
Если хочешь закончить, напиши - закончить
Если продолжаем - напиши продолжаем
закончить
```

## Ограничения

- Каждый пароль содержит 12 символов: по 4 цифры, буквы и знака.
- Длина и набор символов не настраиваются через интерфейс.
- Используется модуль `random`, поэтому пароли не предназначены для защиты важных аккаунтов.
